# work-kit

웹 IDE에서 조건 확인, 설계 선택, 초기 셋업과 검증을 돕는 AI 협업 개발 스킬입니다.

## 시작

IDE의 AI에 다음 문장을 입력합니다.

```text
깃허브 syyahoo/work-kit를 받아서 START.md대로 시작해.
```

터미널에서 직접 받을 수도 있습니다.

```bash
git clone https://github.com/syyahoo/work-kit s
```

다운로드 후 AI에 `s/START.md 읽고 시작해.`라고 입력합니다.

[START.md](START.md)가 세 스킬을 읽고 환경 점검 → 조건 확인 → 설계 선택 → 초기 셋업 → 구현·검증으로 연결합니다.

## 구성

| 스킬 | 역할 |
|---|---|
| [조건 확인](skills/clarify-task-constraints/SKILL.md) | 누락 조건 질문과 담당자 답 반영 |
| [설계·구현](skills/explain-as-you-build/SKILL.md) | 대안 비교·사용자 선택, 설정·설치·실행, 판단 근거 기록 |
| [수동 테스트](skills/guide-manual-tests/SKILL.md) | 첫 화면 확인, 테스트 안내와 관찰 기록 |

다운로드한 준비물 폴더와 과제 작업 폴더는 구분합니다. 실제 과제 규정과 제공 환경의 제한을 우선합니다.
